# Değişiklik Günlüğü (Changelog) - .NET / NuGet

## [1.0.0] - 2026-10-24
### Eklendi
- İlk kararlı sürüm yayınlandı.
- `.NET Standard 2.0`, `.NET 8.0` ve `.NET 9.0` çoklu hedef desteği eklendi.
- `EczaneClient` asenkron HTTP istemcisi ve `Eczane` statik facade eklendi.
- `EczaneModel`, `IlModel`, `GeoLocation` veri modelleri eklendi.
- Kural 1 uyarınca UI kilitlemeyen tam `async/await` (`ConfigureAwait(false)`) mimarisi.
